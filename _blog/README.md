# Weiwei · AI Research Notes

English-language research notes on LLM safety, post-training, and AI agents.

Public blog: https://lilanovo.github.io/blog/

## Writing

Add a leaf bundle at `content/posts/<slug>/index.md`, with its figures in a `figures/` subdirectory. Use the published RSI article as a metadata example. Set `draft: true` while writing and `draft: false` to publish. Home cards show a title, excerpt, date, reading time, type label, and optional figure. Pagination holds ten posts per page; RSS is disabled.

Use `\( ... \)` for inline math and `$$ ... $$` for display math. Figure titles, sources, and interpretation belong in the external caption. Tags and a collapsible table of contents are generated by Hugo.

## Build and publish

The blog uses Hugo 0.147.9 and Node 18+. `npm run build` uses a local Hugo binary or downloads the pinned version. KaTeX 0.16.22 is self-hosted in `static/math/` with its license; no runtime CDN is required.

The GitHub homepage repository stores the Hugo source in `_blog/` and the compiled public site in `blog/`. Jekyll ignores `_blog/` and serves the compiled HTML without changing the academic homepage.

To update the GitHub copy, run from `_blog/`:

```sh
node scripts/export-github.mjs ../blog
```

Then commit the source and `blog/` together. The existing GitHub Pages deployment publishes them. Do not add a root `.nojekyll` file: the academic homepage still uses Jekyll.

The source can also build for the existing Sites address using `npm run build`. GitHub Pages is the canonical public address. A Sites deployment must use its root URL, not the GitHub `/blog/` artifact.

## Checks

`npm run check` validates JavaScript syntax, internal links, assets, anchors, and the search index. Use `SITE_BASE_URL=https://lilanovo.github.io/blog/ npm run check` after a GitHub build.

Paper figures and redrawn results are attributed in each article's figure captions. Reproduction does not imply that third-party figures are covered by a project-wide content license.
